# tariff-project-for-ROP-2026
This repository contains all the code for our simulation project for the University of Toronto Reesarch Opportunity Program (ROP) "Simulating Complexity, Chaos, and Emergence". This includes previous simulation versions in the archive-simulations folder, as well as the most up-to-date version in the full-simulation folder.

Every simulation was coded in Mesa, a Python library designed for programming Agent-Based Models (ABM). In every simulation, there was an agent type for people who bought things (Households, formerly called Consumers), as well as an agent type for producing things (Firm agent). Later versions also included a Government agent for collecting and redistributing tariffs/taxes.
